# LSDA tutorials — with worked solutions

Companion to MATH48132 / MATH68132 at the University of Manchester.

**This build is served at
<https://olatunjijohnson.github.io/lsda-tut-e79eb4874d/>**

It shows the answers: each question has a *Show solution* button and a note on
what the output means. It is the build linked from Canvas for students on the
unit, and it is deliberately kept out of search engines (`robots.txt` +
`noindex`).

**Please do not circulate that link.** The version *without* solutions is
<https://olatunjijohnson.github.io/lsda-tutorials/>, and that is the one to
share.

Rendered output only — sources live in the private course repository.
