We analyse the Lip cancer data in scotland. The data contain, for each of the Scotland counties, the number of observed and expected lip cancer cases among males in Scotland between 1975-1980, and a variable that indicates the proportion of the population engaged in agriculture, fishing, or forestry (aff). The aff variable is related to exposure to sunlight which is a risk factor for lip cancer. The data also contain the shapefile of the Scotland counties and everything can be found in scotland_lip

Row-standardized Weights

We display top 10 rows and columns of the spatial weights matrices. Binary - 1 for neighbor, 0 for non-neighbor. Simple and unweighted. Row-standardized - each row sums to 1, so influence is spread equally across neighbors. These matrices are used in calculating spatial lags and in autocorrelation tests.

  1. Check for the evidence of spatial correlation using Moran I test?

Challenge

# Create spatial weights list lw <- nb2listw(nb_queen, style = "W", zero.policy = TRUE) moran.test(scot$SIR, lw, zero.policy = TRUE) 
# Create spatial weights list
lw <- nb2listw(nb_queen, style = "W", zero.policy = TRUE)
moran.test(scot$SIR, lw, zero.policy = TRUE)

Moran’s I is highly significant (p < 0.000001), indicating strong spatial autocorrelation in SIR. In plain terms: counties with high SIR tend to be near other counties with high SIR, and same for low SIR. This validates the need to account for spatial structure in modeling cancer risk. ## Challenge

Each county is connected to its 3 closest neighbors by distance. Useful when physical proximity is more important than shared boundaries (e.g., for air pollution, etc.).

  1. Calculate the neighbors of each of the regions of Scotland based on distance and map the neighbors obtained.
dists <- dnearneigh(coords, d1 = 0, d2 = 50) plot(st_geometry(scot), border = "lightgray") plot(dists, coords, main = "Distance-Based Neighbors", add= T) 
dists <- dnearneigh(coords, d1 = 0, d2 = 50)
plot(st_geometry(scot), border = "lightgray")
plot(dists, coords, main = "Distance-Based Neighbors", add= T)

Counties within the distance of 50 to each other are connected. Allows flexible neighborhood structures based on absolute proximity. May capture spatial spillover more naturally than contiguity in some contexts.
